# Vaated Tailwindi peale, etapp 4f (päis, menüüd, väikesed vaated, admin) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Viia päis, kasutaja- ja operaatorimenüü, litsentsi-/tugiriba, sisselogimine, üleslaadimismodaalid, Põllud-tabel, Ilm, Laoarvestus, väikesed dialoogid ja teenusepakkuja admin Tailwindi klassideks ja ui komponentideks, nii et ~1100 rida vana CSS-i (`src/index.css` ~940, `src/styles/map.css` ~60, `src/admin/admin.css` ~95) kustuvad ja 4g-le (viimane etapp) jäävad ainult ühised põhireeglid.

**Architecture:** Seitse ülesannet, iga = eraldi commit (Task 5: kaks commit'i) + release + pildid (hele/tume, 1440 ja 1366; päis lisaks 1800) enne/pärast + mõõdetud kõrgused. (1) Skriptid, üleslaadimismodaalid (uus ui `Dropzone`), väikesed dialoogid. (2) Päis, menüüd, litsentsiriba, tugi, App-i kest. (3) Sisselogimine. (4) Täislehe kest + Põllud-tabel (jagatud `fullpage-board-*`/`register-*`/`cell-sub`/`fields-table*` kaovad). (5) Ilm ja Laoarvestus. (6) Admin. (7) Valvur `RETIRED_4F`, README, lõppmõõtmine. Vaatefail läheb `app.css` `@source`-i faili-faili haaval samas commitis, kus tema klassid üle viiakse; uued ui konstandid (`variants.ts`) töötavad ilma `@source`-ita.

**Tech Stack:** React 19 + TS, Tailwind v4.3.5 (`@theme`, `@source`, preflight väljas), class-variance-authority, tailwind-merge (`cn`), Radix (`radix-ui`), vitest (node keskkond, ainult `*.test.ts`), oxlint, Playwright (`scripts/shot.mts`).

**Spec:** `docs/superpowers/specs/2026-11-17-vaated-tailwind-design.md` (siduv; etapp 4.6 „päis, menüüd ja ülejäänud väikesed vaated + admin“) · eelmine plaan (vorm ja keskkonnareeglid): `docs/superpowers/plans/2026-11-19-vaated-4e.md` · töölogid: `.superpowers/tmp/4e-progress.md`, `4d-progress.md` · `src/components/ui/README.md`.

**Märkus vormi kohta:** korduvad käsud on ühiste sammudena A ja L jaotises „Ühised sammud“. Ülesande sammud sisaldavad ülesandespetsiifilise koodi, vana → uus tabelid ja pildikomplektide nimed.
